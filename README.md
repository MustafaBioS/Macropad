# Macropad
Macropad is a hardware project that allows you to bind keys to do certain tasks on your PC

# Why
Because it's a cool project and its also very usefuL!

# Components
This project uses the following:
- SEEDUINO-XIAO MCU
- 4 Tactile Switches
- Rotary Encoder Switch
- 128x32 OLED Display
